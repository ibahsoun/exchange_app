# Exchange Center — Quick Start

**Navigation:** Use the **left sidebar** to switch screens. The **top bar** shows the
clock, connection status (green = connected), a **Refresh** button, and a theme toggle.

### Process a Transaction — *Dashboard*
1. **Select the customer** (search by name or ID).
2. Enter the amount in **Customer Pays** and pick the currency.
3. Pick the **Customer Receives** currency — the amount calculates automatically.
   Use the **swap** button to flip currencies.
4. *(Optional)* Choose a **Receiving Destination** to apply its fee.
5. Click **Process Transaction** → you get a receipt number. **Clear** resets the form.

### Set Rates & Spreads — *Live Rates*
- Compare live sources; set **Store Rate** to *Source* or *Custom*.
- Set the **Spread** (%/Fixed, symmetric or asymmetric) and **Rounding**, then **Save**.
- **Auto Sync** refreshes every 30s; **Refresh** updates once.

### Customers
- **Add New Customer** (name required; phone, email, 1–5 star level).
- Bulk import: **Download Template** → fill it in → **Upload by Excel**.
- Click any row to **view, edit, or delete**.

### Level Points (loyalty fees)
- Per pair, choose **%** or **Fixed**, then set a fee for each star level.
- Higher stars = lower fees; 0 or blank = no extra fee. Click **Save**.
- Fees apply automatically at checkout.

### Destinations (payout locations)
- Enter a **Name** and **Commission** (% or Fixed) → **Add**.
- Edit (pencil) or remove (trash). They appear as options on the Dashboard.

### Transactions
- Search by receipt ID, customer, or pair; filter by **date** and **status**.
- **Export CSV** to download a report.

### Settings
- Manage **currencies**, toggle **live rate fetching**, and enable optional
  features (**Settlement Terms**, **Margins**).

---

**Daily checklist:** ✅ Green connection → ✅ Check Live Rates → ✅ Serve customers on
the Dashboard → ✅ Review Transactions.
